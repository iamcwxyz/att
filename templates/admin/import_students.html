Import Students from CSV

CSV Import Format Requirements:

Required Columns (in this exact order):

  1. student_id - Student ID number (e.g., 2021-001234)
  2. first_name - Student's first name
  3. last_name - Student's last name
  4. birthday - Date of birth in YYYY-MM-DD format (e.g., 2003-05-15)
  5. course - Course code: BSIT, BSCS, BSIS, or BSEMC
  6. year - Year level: 1, 2, 3, or 4
  7. section - Section (e.g., A, B, C)
  8. email - Email address (optional)

Sample CSV Format:

student_id,first_name,last_name,birthday,course,year,section,email
2021-001234,Juan,Dela Cruz,2003-05-15,BSIT,1,A,juan@email.com
2021-005678,Maria,Santos,2003-08-22,BSCS,2,B,maria@email.com

Important Notes:

  • First row must be the header row with column names
  • When updating existing students, only Course, Year, and Section will be updated
  • Student passwords remain unchanged during CSV updates
  • Valid courses: BSIT, BSCS, BSIS, BSEMC
  • Valid years: 1, 2, 3, 4
